# Atlas Istoric pe ramura separată `atlas-istoric-android`

Această ramură conține proiectul Android Atlas Istoric în directorul `atlas-istoric/`.
Repository-ul original Biblioradar și ramura `main` nu sunt modificate.

Compilarea automată se află în Actions → **Atlas Istoric - Android APK**.
APK-ul debug este disponibil ca artefact doar după un build reușit.
Pentru păstrarea datelor între instalări succesive este necesară semnarea
constantă a versiunilor release și exportul periodic al bazei personale.
